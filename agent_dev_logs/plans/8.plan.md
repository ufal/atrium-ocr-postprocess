1. ~~The columns, tests, docs, samples.~~ Done 10-22; the names made one form, `_ratio`, on 10-23.
2. **The rerun.** After `test` is pushed: `git pull` in the cluster checkout
   (`/lnet/work/projects/atrium/GITHUB/atrium-ocr-postprocess`), then `sbatch tools/page_stats_rerun.sh` from its
   root (ARUP and ARUB under `DATA`, default `/lnet/work/projects/atrium`). It refuses a collection that already
   holds `*_1210r` output. The first submission (job 7271655, 10-22) found no collection: the job looked for them
   next to the checkout; since then the data root is a setting of its own. An output written before the 10-23
   rename has the short names and is removed before the job runs again.
3. **Read the two reports** (`/lnet/work/projects/atrium/{ARUP,ARUB}/page_stats_1210r_report.md`). A FAIL names the check and the rows:
   - a changed old column means the inputs or the code differ from the 10-12 run, and is explained before anything
     is handed over;
   - missing pages or files are matched to the skips the report lists.
4. **Report on #8**: the reports' scope, counts, skips and errors, in a comment.
5. **Release** the next `v1.12.x-beta` with the columns and the two tools; the CONTRIBUTING row then.
6. **Hand-over**: the `page_stats_1210r.csv` tables to Dana, as the 1210 outputs were.
