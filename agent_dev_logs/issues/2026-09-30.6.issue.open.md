Rename from alto-postprocess to ocr-postprocess the GH repo link and adapt the source code+docs to this change

The whole focus on ALTO XMLs should be shifted towards any text-containing files, but the developed pipeline shall be preserved


The tool now reads OCR output in several formats (ALTO, PAGE XML, hOCR, ABBYY, JSON) and any text-bearing file (#31), so the name follows the scope: **`ufal/atrium-ocr-postprocess`**, as agreed at the AMČR meeting on 30 September. The pipeline itself (steps, scripts, categories, calibration, scoring) stays as it is.

A rename touches three layers:

1. **The repository.** GitHub renames it and redirects git and web URLs, but not the Pages site or the GHCR images. So README and CITATION, the images (`ghcr.io/ufal/atrium-ocr-postprocess` and `…-api`), the hub's lists and E2E, the ARUP-CAS fork, the SSHOMP record and the Galaxy wrapper all need updating.
2. **The service identity.** `/info` `service` and the spec's `x-atrium-service` change. The hub's release gate fails any release whose service id changed, so it first has to learn to accept a declared rename.
3. **The program id in the record.** `alto-postprocess` is an originator and block owner in the shared contract. `ocr-postprocess` is added as its successor (both accepted on read), in the same schema round as atrium-project#71 and #73. Records already written keep their stamps.

**Timing:** after the 16 October time-box release of ufal/atrium-ocr-postprocess#1, ufal/atrium-ocr-postprocess#2, ufal/atrium-ocr-postprocess#5 and ufal/atrium-ocr-postprocess#3, and before the S2 pilot pins tool versions.

**Acceptance**
- [ ] the repository is `ufal/atrium-ocr-postprocess`, and the old URL redirects
- [x] the hub release gate accepts the declared rename and still rejects an undeclared one
- [x] records written after the rename carry `ocr-postprocess`; older records still load, merge and pass the origin check
- [x] images are published under the new names, and the hub E2E is green against them
- [x] README, CITATION, Pages, hub references, ARUP-CAS fork, SSHOMP record and Galaxy wrapper are updated

**Out of scope:** renaming the ALTO-specific scripts (`extract_ALTO_2_TXT.py`, …); any change to categories or scoring; the born-digital path (ufal/atrium-digital-convert#2, ufal/atrium-alto-postprocess#29), which will reuse this repository's readers.

Depends on: the gate change and the schema round in atrium-project (#NEW-SPLIT, #NEW-BASELINE). Plan: `agent_dev_logs/plans/56.plan.md`.
