## Request summary

Following Dana's review of the existing ALTO post-processing results, add page-level ratios for the five line categories to the aggregated statistics CSVs.

The current statistics contain the number of lines in each category, but ratios make it easier to compare pages of different sizes and evaluate overall page quality.

Dana specifically requested the following columns:

| Column | Definition |
|---|---|
| `clear_rat` | `Clear / (num_lines - Empty)` |
| `noisy_rat` | `Noisy / (num_lines - Empty)` |
| `trash_ratio` | `Trash / (num_lines - Empty)` |
| `non-text_rat` | `Non-text / (num_lines - Empty)` |
| `empty_rat` | `Empty / num_lines` |

The first four ratios exclude `Empty` lines from their denominator. The `empty_rat` denominator includes all lines.

## Scope

1. Extend the page-statistics aggregation to calculate the five requested ratios.
2. Include the columns in the per-document `stats_<doc>.csv` files and the global page-statistics CSV, using the configured output paths.
3. Handle pages with zero denominators explicitly and consistently.
4. Add regression tests and update the output-schema documentation.
5. Regenerate the statistics for the complete corpus using the existing classified line CSVs, rather than validating only against the shipped sample files.

Keep the existing category counts, categorization rules, quality scores and other statistics unchanged.

## Acceptance criteria

- [ ] All five requested ratio columns are present in the page-statistics CSV outputs.
- [ ] Ratios are calculated from the existing per-page category counts using the definitions above.
- [ ] Ratios are represented as decimal fractions in the range `[0, 1]`, not percentages, and rounded to four decimal places consistently with the existing numeric statistics.
- [ ] Pages containing only `Empty` lines produce a valid `empty_rat` of `1.0`; the first four ratios are undefined because their denominator is zero.
- [ ] Any page with `num_lines == 0` produces undefined ratios rather than division-by-zero errors or infinite values.
- [ ] Tests cover mixed-category pages, pages without `Empty` lines, empty-only pages and zero-denominator handling.
- [ ] The per-document and global statistics outputs use consistent schemas and include the new columns for every applicable page.
- [ ] `docs/reference/outputs.md` and the relevant usage documentation describe the new columns and formulas.
- [ ] Statistics are regenerated for the full corpus, not just the sample dataset.
- [ ] The full-corpus run is checked for missing outputs, skipped inputs and unexpected changes to existing statistics.
- [ ] The run's input scope, output locations, processed document/page counts and any errors or skipped inputs are reported.

## Implementation notes

The aggregation currently has separate handling for pages with and without scoreable text. Ensure the new columns are populated consistently in both paths.

Preserve the column names proposed by Dana unless a naming change is explicitly agreed upon before implementation.
