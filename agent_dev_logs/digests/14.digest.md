## 🧭 2026-11-16 — the builder against the ATR's docproc (from the draft)

| Part             | Where                                     | Behaviour                                                                             |

### What the ATR gives that the builder ignores

Never read anywhere in the code (the schema of comment 1 on atrium-project#84 defines them):
- `readingOrderRole` and `metadata.readingOrderExtensions` (footnotes with `bodyRefBlockIds`, sidebars); the slice
  plan's promise "`readingOrderRole` kept for the order of footnotes and sidebars"
  (`plans/doc-schema-v2.plan.md:55-56`) is not implemented;
- `continuedFrom` / `continuedTo`: a block continued on the next page stays two unrelated sets of lines;
- `parent` / `children`, `parentBlockId` / `captionBlockId`: a figure's OCR child (`.t0`) and a caption land wherever
  their own `readingOrder` puts them;
- `crossPageClusters` (running headers and footers): kept in place on every page;
- block `type`: stored in `ReadBlock` (`docproc.py:85`, `261`) but never consulted; `IMAGE_TYPES` (`:39`) unused.

### Side effects worth knowing

- The order feeds the scoring passes that look at neighbours: "Noisy surrounded by Trash" (`classify_TEXT.py:893-910`)
  and the inverted-scan sweep (`:986-1001`). A wrong order changes categories, not only the text.
- `content.text` has no page or block separator (`build_record.py:215`); the old batch path joined pages with `\n\n`
  (`document_hook.py:623`).
- A table without `cellGrid` falls back to its `content`, which the schema allows as HTML or a pipe table
  (`document.actual.schema.json:572`): such rows reach the record as markup.
- A long one-line paragraph unit can exceed the perplexity window and fail the build
  (`service/text_inference.py:316-338`; the hub's Q6).

### Fixtures

`tests/fixtures/docproc/scan.atr.docproc.json` and `mixed.atr.docproc.json` are hand-written in the ATR's shape. No
fixture has continuations, roles, extensions, `crossPageClusters`, `.f/.h/.c` ids, an ATR footnote or sidebar, two
columns, or a paragraph across pages. No real ATR output is in this repository or digital-convert.
